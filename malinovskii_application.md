**[ НАЗВАНИЕ ПРОЕКТА ]**

“Название ещё не придумано”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Информация о поступлении в китайские вузы разбросана по многим сайтам, на разных языках и в разном виде. Чтобы узнать про программы, требования, стоимость, стипендии и сроки, приходится всё искать самому. Сравнивать вузы по одним критериям неудобно, а дедлайны легко пропустить.

Эта тема близка мне лично: я изучал китайский язык и сдал HSK 2, четыре раза был в Китае, в том числе два раза с лицеем. Я самостоятельно посетил многие университеты и взял контакты студентов, которые там учатся. Эти поездки и изучение языка сделали Китай по-настоящему интересным для меня, и я хочу помочь другим школьникам, которым тоже интересно учиться там, не потеряться в процессе поступления.

Существующие каталоги часто на иностранном языке и ограничиваются описанием вузов. Мне хочется добавить то, чего там обычно нет: **единое сравнение по понятным критериям и личный план поступления**. Цель - не справочник, а инструмент, который проводит абитуриента от выбора вуза до подготовки документов.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Заказчик проекта - студент из Китая, который учится в китайском вузе. Он будет подсказывать, как всё устроено изнутри, и проверять данные об университетах.

Пользователи сайта:

* Российские школьники, преимущественно старшей школы, которые думают о поступлении в Китай
* В дальнейшем - консультанты по зарубежному образованию

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]**

Продукт разрабатывается как адаптивный веб-сайт и должен работать:

* На компьютере - в современных браузерах
* На телефоне - в мобильном браузере, с адаптированным под небольшой экран интерфейсом

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Сайт будет предоставлять следующие возможности:

* Каталог университетов: направления, программы, требования, стоимость, стипендии
* Поиск и фильтры по специальности, языку обучения, цене и другим параметрам
* Сравнение нескольких вузов по ключевым характеристикам: стоимость обучения, язык обучения, специальности, стипендии, сроки подачи документов
* Личный трекер поступления: задачи, этапы, дедлайны, прогресс
* AI-помощник для подбора вузов по интересам пользователя - как расширение, если хватит времени

Основа проекта - каталог, сравнение и трекер. AI - дополнительная функция. К первой версии планируется каталог из 5-10 вузов.

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Существующие каталоги китайских вузов часто доступны только на иностранном языке и ограничиваются описанием университетов. В них обычно нет единого сравнения по понятным критериям и личного плана поступления. Подробный анализ аналогов будет проведён на первом этапе работы (25 октября - 8 ноября 2026).

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

* HTML / CSS / JavaScript - для интерфейса
* Python - для серверной части
* SQLite - база данных для вузов, программ и задач пользователей
* API AI-модели - для AI-помощника (при необходимости)
* Хостинг - для размещения рабочей версии сайта

3. 23 ноября - 13 декабря 2026: делаю каталог (страницы, карточки вузов, поиск и фильтры) и наполняю его данными по 10-15 вузам

**[ ВОЗМОЖНЫЕ РИСКИ ]**

* **Данные устаревают.** Условия поступления, цены и стипендии меняются. Беру информацию с официальных сайтов, сохраняю ссылки и обновляю данные.
* **Информации слишком много.** Все вузы Китая не охватить, поэтому начну с 10-15 и буду расширять каталог.
* **Данные на китайском.** Мой уровень языка пока базовый, поэтому буду проверять информацию с помощью консультанта, переводчика и англоязычных страниц вузов.
* **Не хватит опыта.** Бэкенд, база и AI могут оказаться сложнее. Буду делать проект маленькими шагами и осваивать нужное по ходу.
* **Не хватит времени.** Если не успею всё, оставлю самое важное: каталог, поиск, сравнение и базовый трекер.
* **Ошибки и неудобный интерфейс.** Буду тестировать части сайта по мере готовности и учитывать отзывы.
* **AI даст неточные рекомендации.** Подбор будет опираться на данные каталога, а рядом с вариантами я покажу ссылки на официальные сайты. Если с AI не получится, подбор будет работать через обычные фильтры.
